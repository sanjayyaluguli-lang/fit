SYS VAL Dashboard Setup

A click-by-click manual for the owner of the dashboard. It goes from three files to a weekly Slides deck per project, with TPMs entering Test Equipment and Support Required through a web form. Every formula can be copied with one button, and sample data lets you check each step against known numbers.

1
Before you start

Collect the three files and a Drive folder

Everything you paste later comes from these files. The destination folder is where the weekly decks will appear.

  1. Open Code.gs, InputForm.html and SYS_VAL_Dashboard_Template.pptx on GitHub (sign in if asked; the repository is yours).
  2. For each of the two code files, click Raw (top right of the file), then Ctrl+A, Ctrl+C when you need it in step 7. For the .pptx click Download raw file (the download arrow).
  3. In Google Drive click + New → New folder, name it SYS VAL Decks, and open it.
  4. Copy the folder ID from the address bar and keep it in a note: drive.google.com/drive/folders/0B9q…Lk7.

You need a Google Workspace account. Personal Gmail works for testing, but the form cannot record who saved and TPMs outside your organisation cannot open it.

6b · Show the percentage in the middle of each ring

Google Sheets cannot write text inside a doughnut hole. The usual workaround is a transparent Scorecard chart placed on top of the ring.

  1. Click an empty cell, then choose Insert → Chart.
  2. Setup → Chart type → Scorecard chart (under "Other"). Set Key value to B3 (B7, B11, B15, B19 for the other rings).
  3. Customize → Chart style: Background colour → None, Border colour → None.
  4. Customize → Key value: Number format → Percent (or Custom 0.0%), font size about 24, bold, dark grey.
  5. Customize → Chart & axis titles: leave the title empty.
  6. Close the editor. Drag the scorecard into the hole of the ring and drag its corner until it fits. A chart created later sits on top, so the number stays visible.

  5. Back in Code.gs, replace the folder placeholder with your folder ID from step 1. Leave TEMPLATE_ID for step 11.
  6. Press Ctrl+S.

Script and form

Run the setup and grant permissions

The first run asks for your permission to read and write your Sheet, Slides and Drive. It also creates the three input tabs.

  1. Go back to the Sheet tab and reload the page (F5). After a few seconds a menu Dashboard Generator appears next to Help.
  2. Choose Dashboard Generator → Setup Input Tabs (one-off).
  3. A dialog "Authorisation required" opens. Click OK or Continue, then pick your account.
  4. If you see "Google hasn't verified this app", click Advanced, then Go to SYS VAL Dashboard (unsafe). This is your own script, so this is expected.
  5. Review the access list (Google Sheets, Slides, Drive, external requests for the form, and triggers) and click Allow.
  6. Run Setup Input Tabs once more if it stopped at the permission screen.

Script and form

Publish the form as a web app

Publishing gives you one link for all TPMs. The form runs as you, so TPMs need no access to the Sheet and cannot edit it directly.

  1. In the Apps Script tab click Deploy (blue button, top right) → New deployment.
  2. Click the gear icon next to Select type → Web app.
  3. Description: TPM Input v1. Execute as: Me. Who has access: Anyone within <your organisation>.
  4. Click Deploy. Approve permissions again if asked.
  5. Copy the Web app URL (ends in /exec) and click Done.
  6. Open the URL in a new tab to test it, then send it to your TPMs.

Generate the first deck

This is the full pipeline: tracker numbers, form input and template come together in a new deck.

  1. In the form click Generate deck. It takes about 20 seconds.
  2. Click Open deck in the green message. The deck is also in your SYS VAL Decks folder.
  3. From the Sheet you can also use Dashboard Generator → Generate Dashboard for a Project… (type the exact project name) or Generate All Projects.
You should see

  • Top: your project name, its release, and "Updated cw" plus the current week.

  • Support Required row 1 is filled and its status is red; rows 2 and 3 are empty.

14
Run it

Schedule the weekly run and go live

From now on one deck per project is created every Monday morning.

  1. In the Sheet choose Dashboard Generator → Schedule Weekly (Mon 07:00, all projects).
  2. Check it in Apps Script: click the clock icon Triggers in the left bar. You should see one trigger: generateAllDashboards, Time-based, Week timer, Every Monday, 7am to 8am.
  3. Switch Raw_Data B1/B2 from the sample sheets to the real Requirements tracker and Bug tracker (allow access again).
  4. Delete the test rows: open the form, clear them, Save.
  5. Tell TPMs to save by Friday each week. The form shows when each project was last saved.

Unknown project "…"The name typed or sent does not exactly match the Projects tab.
Form says "No projects yet"Add at least one row to the Projects tab.
Form behaves like an older versionDeploy a new version (step 10 note).
"Last saved … by unknown"The TPM is outside your Google Workspace organisation, so Google hides their email.
#REF! "You need to connect these sheets"Hover the cell and click Allow access (step 4).
#REF! "Array result was not expanded"Something is typed in the cells an import needs. Clear the area below or right of the formula.
Values on the slide show as 0.997 instead of 99.7%Set the percent format on that Calculation_Engine cell (step 5).
Text in double braces left in the deckThe key does not exist or is spelled differently. The toast and View → Executions in Apps Script list the unmatched placeholders.
"Exception: You do not have permission"Run any menu item once yourself and accept the permissions (step 8). For the trigger, you must be the one who created it.
